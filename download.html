安装步骤

  1. 点上面的按钮下载安装包（若没反应，长按按钮选「下载链接」）
  2. 打开下载好的文件，点「安装」
  3. 系统询问时，允许「安装未知来源应用」
  4. 装好后桌面出现图标，点开即可使用，全屏运行、可离线

提示：如果提示「应用未安装」，多半是手机系统版本过旧或安装权限没开， 可在「设置 → 应用 → 特殊权限 → 安装未知应用」里允许你用的浏览器。

另一种方式：不装 APK，直接装成网页 App

用 Chrome / Edge 打开 计算器主页， 点页面里的「立即安装」，或右上角 ⋮ →「安装应用」， 效果和 APK 一样（桌面图标、全屏、离线），而且体积更小、自动更新。
此方式需要 Chrome / Edge，装 APK 则任何浏览器都可以。
